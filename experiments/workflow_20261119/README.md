# 캡스톤 작업 보조 코드

AWS 32개·1,000개 시나리오 준비, 실행·감시, 결과 검사, CSV 패키징, 공개 실험 자료 검증, 전달 기록 생성에 사용한 보조 코드 전체다.

각 파일은 당시 작업 폴더와 원본 자료 배치에 의존한다. 계정·인스턴스·알림 주소는 예시 값으로 바꿨다. 실제로 실행할 때는 입력 파일 경로와 대상 자원을 확인해야 한다. 현재 재현 실행은 [선별 셀 실험 안내](../team_six_outputs_20261117/README.md)를 따른다. 파일별 원본과 공개본 해시는 [목록](source_index.json)에 있다.
