# 충전 시나리오 시뮬레이션

[예비 32건](pilot_32_summary.csv)과 [딥러닝 학습용 1,000건](degradation_training_1000.csv)은 LG M50 계열 물리 모델로 충전 조건을 바꿔 계산한 출력입니다. 1,000건은 초기 온도, 충전 전류, 시작 충전 상태, 냉각 조건을 조합했습니다. 열화 지표와 데이터 분할은 [CSV 설명](dataset_notes.txt)에 있습니다.

| 코드 | 역할 |
| --- | --- |
| [시나리오 실행기](../../simulation/risk_scenarios.py) | 조건별 온도·열화 계산과 이력 저장 |
| [1,000건 데이터 구성](../../simulation/risk_dataset1000.py) | 시나리오 조합, 검증과 데이터 분할 |

열화량은 모델이 계산한 값입니다. 실측 수명과 발화 여부를 평가하려면 해당 관측 자료가 필요합니다.
