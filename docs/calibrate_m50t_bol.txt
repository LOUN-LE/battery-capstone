LG M50T 초기 용량·전압의 유효 초기상태 보정

코드: simulation/calibrate_m50t_bol.py
검사: simulation/test_calibrate_m50t_bol.py
이 프로그램은 초기 RPT0 한 곡선을 맞추는 후보 탐색이다. 장기 SOH 곡선이나
수명 정확도를 검증하는 프로그램이 아니며 승인된 SOH 합격선으로 판정하지 않는다.

두 변수와 물리 제약
- s_Q: 음·양극 활물질 체적분율을 함께 곱한다. Qn/Qp는 유지한다.
  초기 농도가 같으면 기존 입자 리튬 재고도 s_Q에 비례하므로 이를 먼저 반영한다.
- delta_Q_Li_Ah: 초기 음극 농도에 delta*3600/(F*A*Ln*scaled_epsilon_n)를
  더한다. 표적 입자리튬은 s_Q*기준입자리튬 + delta다. 정격5Ah와 혼동하지 않는다.
- solve(initial_soc=.2)는 바뀐 총 입자리튬을 보존하는 eSOH 초기화를 사용한다.
  각 실제 실행에서 첫 표본 입자리튬을 표적값과 비교한다.
- 체적분율+공극률<=1, 0<초기농도<최대농도를 검사한다. 탐색영역은
  s_Q=[.85,1], delta=[-.4,.4]Ah다. 이는 물리적으로 허용되는 수치 탐색범위이며
  문헌이 보증한 제조 편차나 신뢰구간은 아니다. 경계 근처의 해는 별도 해석한다.
- 확산·반응·열화 속도계수는 바꾸지 않는다. 활물질 분율 변경으로 유효 반응면적이
  달라질 수 있으므로 이를 단순한 출력 용량 재정규화라고 해석해서는 안 된다.

실험과 목적함수
nominal25°C 등온 SPMe+OKane2022에서 -1.5A충전/4.2V유지·.05A종료,
휴지, .5A방전·2.5V종료를 실행한다. v1/v2의1h휴지는논문기반가정이다.
정확한처리곡선과대응되는C원자료BoL/Slow/long01을확인한v3는
초기120s휴지와방전전7230s휴지를명시한다. Ns0경계120.0460057s,
Ns3+4경계7230.0803434s를최적화전최근접초로반올림했다.
논문1h설명과기록2h+30s의차이는원인미확인이며일치한다고쓰지않는다.
초기SOC.2는 가정이며 실제5회형성
과정과 온도이력은 재생하지 않았다. 모델과 실측 방전용량은 각각 시작값을 뺀다.
C 원시 RPT0만 사용한다. C 측정 용량의2~80% 구간 81개 고정 좌표에서
전압 잔차를 구하고 전체 방전용량 잔차 하나를 추가한다. 전압 잔차는
20mV*sqrt(81), 용량 잔차는20mAh로 나눈다. 이 수치는 최적화 가중치이며
SOH RMSE1%p 등 사용자 합격 기준과 다르다. 후보별 비교구간 축소나 외삽은 없다.

근거 보존과 실행 한계
declared_experiment.json에 데이터·코드 해시, 변수·경계·가중치·고정좌표·
솔버·mesh·초기값을 먼저 기록하고 코드 원문도 복사한다. 실제 패키지 버전과
OKane2022 구현 해시는 runtime_environment_before_fit.json에 먼저 기록한다.
모든 실제 후보의 원시 곡선·수치·오류를 candidate_NNN.json/npz로 보존한다.
실패 후보는 고정 차원의 큰 잔차를 반환한다. 실패 후보로 얻은 penalty
Jacobian을 물리 민감도라고 보고하지 않는다. 시작점/최종 Jacobian은 사용된
후보가 모두 실제 유효한 결과인지 확인하고 수치 rank·condition을 기록한다.
rank2만으로 구조적·실용적 식별성이 증명되는 것은 아니다.

두 시작점 최적화와 제한된 조건부 프로파일을 수행한다. 프로파일은 고정 s_Q에서
delta를 제한 횟수로 재최적화한 값이며, 성공하지 않은 프로파일을 최적값이나
신뢰구간으로 표시하지 않는다. 두 시작점의 수렴 여부·해 차이·경계 도달을
함께 확인해야 한다. 전체 실행 성공과 최적화 수렴 성공은 다른 필드다.

선택한 C 후보의 파라미터를 먼저 동결한 뒤 더 촘촘한 mesh와 허용오차로
검사한다. 그 후에만 D원자료를 열어 같은 고정 예측을 평가한다. D에 맞춰
용량을 재정규화하거나 모델을 선택하지 않는다. D는 기존 공식 다운로드
기록에 있는 원자료 해시와 일치해야 한다. 파라미터·코드·기준 파라미터 구현
불변을 끝에서 다시 확인한다. D용량 오차·전압 오차는 SOH 열화오차가 아니다.

v1은29회 실제 계산과 별도fine검사를 완료했지만 두 시작점 모두 nfev상한으로
종료했다. v1은 calibration_source_frozen.py와 함께 보존했으며 수렴을 선언하지
않는다. v2는 같은 목적함수·물리·범위를 유지하고 v1의 C최적화 끝점만 이용해
시작한다. D평가 수치로 시작점·가중치를 바꾸지 않았다.

예산을 예약한다. 임의의 이전Linux상태나 셀4수명 궤적은 불러오지 않는다.
CLI가끝나면 파일에 기록된 실제 상태를 확인한다. AWS기동이나 이메일은 하지 않는다.
