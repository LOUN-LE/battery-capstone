# D셀 열화 재현 검토 기록

2026년 11월 19일 기준으로 D셀의 첫 열화 구간 3,940개 계산과 두 성능시험 비교를 완료했다. **계산은 끝났지만 실제 용량 감소를 과소예측해 기존 오차 기준을 충족하지 못했다.** 보호막 성장이나 도금이 실제 열화 원인이라고 확정한 결과는 아니다.

대상은 Imperial 공개 자료의 LG M50T, 실험 2,2, 명목 25°C D셀이다. 최초 성능시험 RPT0에서 다음 성능시험 RPT1까지 같은 상태를 이어 계산했다. 이 실험의 충전율 범위는 70–85%이며, 25°C는 시험 장치의 바닥 냉각 설정이다. 셀 전체가 항상 25°C였다는 뜻은 아니다. [원자료와 실험 설명](https://zenodo.org/records/10637534)

| 비교 항목 | 모델 | 실측 |
| --- | --- | --- |
| RPT0 용량 | 4.837102 Ah | 4.823331 Ah |
| RPT1 용량 | 4.813731 Ah | 4.718293 Ah |
| 용량 감소 | 0.023371 Ah | 0.105038 Ah |
| 각자의 초기 용량 대비 감소 | 0.483156% | 2.177708% |

모델은 감소량을 0.081667 Ah 적게 예측했다. 두 시점의 수명 상태 오차는 평균제곱근오차 1.198229%p, 최대절대오차 1.694552%p다. 기존 기본 기준은 각각 1%p 이하와 2%p 이하를 모두 만족하는 것이므로 이번 두 점의 참고 판정도 기준을 넘었다. 최초 시점은 정규화 때문에 오차가 자동으로 0이며, 이후 비교점은 한 개뿐이다. 전체 13회 성능시험 중 11회와 수명 종료 시점은 평가하지 않았다. [실제 점수 기록](../experiments/team_six_outputs_20261117/evidence/long_D_baseline/d_long_score.json)

전압 곡선은 방전한 전하량을 기준으로 겹치는 구간에서만 비교했다. 각 곡선을 자기 용량으로 정규화하면 전압 평균제곱근오차는 RPT0 29.171 mV, RPT1 26.963 mV다. 용량 차이를 숨기지 않는 공통 실측 초기 용량 축에서는 각각 34.361 mV와 64.019 mV다. 전압에 사전 합의된 합격선은 없으며, 이 숫자로 합격을 선언하지 않는다. 두 성능시험 모두 모델이 독립적으로 2.5 V에 도달했을 때 종료했다. 실측 방전시간을 모델 종료시간으로 강제하지 않았다. [RPT1 공통 용량 축 비교](../experiments/team_six_outputs_20261117/evidence/long_D_baseline/RPT1_common_measured_RPT0_capacity.csv)

계산 시간은 서로 다른 범위를 구분해 남긴다.

| 기록 | 시간 | 해석과 근거 범위 |
| --- | --- | --- |
| 앞선 짧은 관측 재생의 AWS 비교 | 56.44초 | 당시 콘솔 관측을 정리한 기록이며 이번 공개 묶음에는 원시 타이밍 JSON이 없다 |
| 로컬 사전 시나리오 비교 | 109.45초 | 네 조합의 여섯 번 실행을 두 배치에서 수행한 경과시간 합계 |
| 이번 로컬 장기 기준 실행 | 79,020.528초, 약 21시간 57분 | 체크포인트에서 이어 누적한 실행 경과시간 |

짧은 시간 비교를 3,940개 장기 구간이나 1,000개 시나리오의 소요시간으로 확대하지 않는다. 이번 장기 실행은 AWS 실행이 아니다. 누적 경과시간에는 준비, 수치 계산, 저장 등이 포함되며 순수 계산기 시간이나 CPU 사용시간을 따로 측정한 값이 아니다. 최초 시작부터 최종 종료까지의 달력상 간격은 약 22시간 4분으로 재개 사이의 공백을 포함한다. 한국 시각으로 11월 18일 11시 09분에 시작해 19일 09시 14분에 끝났다. [최종 실행 기록](../experiments/team_six_outputs_20261117/evidence/long_D_baseline/progress.json)

짧은 590초 관측 구간에서는 다음 네 조합을 확인했다.

- 보호막 성장과 도금 반응 모두 활성
- 보호막 성장 중지
- 도금과 박리 및 비활성 리튬 전환 중지
- 두 반응 모두 중지

총 실행 시도는 여섯 번이다. 첫 네 번 중 두 번은 보호막 두께가 고정되어야 한다는 검사에서 실패했다. 두께는 변화하는 전극 면적의 영향을 받으므로, 보호막 반응 전류와 리튬 소비가 정지하는지를 검사하도록 바로잡고 해당 두 조합을 재실행했다. 재실행 두 번은 통과했다. 실패 기록도 보존한다. 네 조합은 같은 준비 상태에서 출발하지만 균열과 활물질 손실은 계속 활성이다. 따라서 보호막만 존재하는 셀이나 도금만 존재하는 셀을 뜻하지 않는다. [최초 네 번](../experiments/team_six_outputs_20261117/evidence/local_mechanism_switch_20261118.json), [두 번 재실행](../experiments/team_six_outputs_20261117/evidence/local_mechanism_switch_retry_20261118.json)

장기 실행을 완료한 것은 두 반응을 모두 활성화한 한 조건이다. 다른 세 조합을 장기 구간까지 계산한 것은 아니다. 실행 중 전류 구간을 묶는 변경은 같은 여덟 구간을 별도 계산한 결과와 대조했다. 상대 상태 차이는 약 6.53×10⁻¹⁰, 전압 차이는 약 2.21×10⁻¹⁰ V였다. 이 제한된 확인을 장기 전체의 격자 수렴이나 물리 정확도 검증으로 확대하지 않는다. [구간 묶기 대조](../experiments/team_six_outputs_20261117/evidence/long_D_baseline/grouping_physical_audit.json), [전체 구간 기록](../experiments/team_six_outputs_20261117/evidence/long_D_baseline/steps.json)

현재 해석에는 다음 제한이 남는다.

- 관측이 없는 구간은 0 A 휴지와 25°C로 가정했다. 실제 이력을 완전히 복원한 것으로 인정하지 않는다.
- 단계별 모델 전압의 최댓값은 4.5142 V로 명목 운전 상한 4.2 V를 넘었다. 원시 전류를 적용한 단계의 조기 종료와 상태 제약도 추가 검증 대상이다.
- 초기 짧은 휴지 전압으로 균일 농도 상태를 준비했다. 내부 농도 분포가 실측으로 확인된 상태는 아니다.
- D셀은 이전에도 검토한 셀이다. 이번 결과를 새로 숨겨 둔 검증 자료의 성과로 부르지 않는다.
- 공개 자료의 열화 분석값은 저율 전압 곡선을 역산한 추정값이다. 모델 내부의 보호막 소비량, 도금 재고, 비활성 리튬, 활물질 손실과 정의가 같지 않으며 직접 원인 라벨로 사용할 수 없다. [열화 분석 방법 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC9709825/)
- 반응들이 서로 영향을 주므로 반응을 끈 결과의 차이를 더해 실제 원인 비율로 만들 수 없다. 현재 코드의 반응 중지는 기존 손실을 지우지 않고 해당 시점 이후 반응률을 바꾸는 실험이다.

[짧은 결합 모델 보고서](../experiments/team_six_outputs_20261117/evidence/coupled_report.json)와 [팀 전달용 단일 셀 예시](../examples/team_single_cell_20261117)는 계산 연결과 전달 형식을 확인하는 자료다. 수명이나 실제 열화 원인을 검증했다는 근거로 사용하지 않는다. 공개 증거 파일의 개인 경로는 정리하며, 원본 바이트 해시는 별도 매니페스트에 보존한다.

남은 목표는 관측 공백과 온도 가정의 영향을 확인하고, 이번 용량 감소 오차를 줄일 근거를 찾는 것이다. 이후 고정된 조건으로 다른 세 반응 조합과 나머지 성능시험을 비교하고, 동일한 전압 역산 절차로 열화 분석값을 평가해야 한다. 같은 배터리 관측 입력을 사용하는 머신러닝과 딥러닝의 시간·선별 정확도 비교도 아직 완료되지 않았다.
