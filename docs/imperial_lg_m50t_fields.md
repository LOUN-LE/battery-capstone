# Imperial LG M50T 데이터 항목

| 파일 | 들어 있는 값 | 이번 계산에서의 역할 |
| --- | --- | --- |
| 저율방전 시계열 | 시간(s), 전압(V), 전류(mA), 누적 전하량(mAh), 실측 셀 표면 온도(°C) | 전류를 A로 변환해 입력. 실측 전압은 계산 전압과 비교. 실측 표면 온도는 기록하고 모델은 25°C 등온으로 계산 |
| 실험 장비 원본 | 위 시계열, 장비 제어 모드·단계·사이클 번호, 용량·에너지 기록 | 방전 전 충전·휴지 조건 식별 및 시작 상태 준비 |
| 실험 메타데이터 | 셀 ID, 명목 냉각 온도, 노화 시험의 SOC 범위, 장치·채널, 노화 구간 수 | 실험 2,2의 셀 한 개 선택. 70–85%는 노화 조건의 범위 |
| 정기 성능 시험 요약 | 저율·중율 방전 용량, 펄스 저항, 용량 유지율(SOH), 논문 저자가 추정한 양·음극 활물질 손실(LAM)과 리튬 재고 손실(LLI) | 장기 용량 평가에 쓸 수 있는 별도 자료. 시점별 열화 정답으로 사용하지 않음 |
| 노화 구간·사이클 요약 | 시험 날짜, 온도·전압 통계, 충·방전 용량, 효율, 누적 전하·에너지 처리량 | 사용 이력과 장기 열화 구간 확인 |

| 디지털 트윈 출력 | 단위 | 해석 |
| --- | --- | --- |
| 음극 SEI 두께 / SEI 누적 손실 | nm / Ah | 모델의 보호막 성장과 리튬 소비 |
| 금속 리튬 / 비활성 리튬 농도 | mol/m³ | 모델의 도금 잔량과 비활성 리튬 |
| 음극 입자 균열 길이 | m | 모델의 평균 균열 길이 |
| 음극 / 양극 활물질 손실률 | % | 각 전극의 모델 출력 |
| 음극 공극률 | 0–1 | 음극 공간에서 공극이 차지하는 비율 |

모델은 PyBaMM SPMe, OKane2022, 25°C 등온, 음극 균열과 양·음극의 응력 기반 활물질 손실을 사용한다. 측정된 시간별 SOC 대신 완충을 가정하고 공칭 5Ah와 전류 적산으로 계산한 추정값을 사용한 부분은 이전 전달용 CSV에 표시돼 있다. 모델 내부 지표는 관측으로 확정한 열화 원인과 구분한다. 정기 성능 시험 요약의 LAM/LLI도 저자의 곡선 적합 결과다.
