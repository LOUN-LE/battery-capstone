PyBaMM 수치 오차 수정·검증 경로 — 2026-11-03

목적
100 EFC의 3.3A−3.0A SOH 차이가 RPT 정밀도에 따라
0.001101249 → 0.000866000 → 0.000892864 %p로 변했다.
순위 유지와 정밀도 통과를 구분한다. 이 결과만으로 실제 수명 차이를
인정하거나 SOH 80%까지의 실행을 재개하지 않는다.

코드
simulation/rebuilt_lifetime.py: 독립 후보 엔진. 고정된 SPMe/OKane2022
기준 물리 설정을 사용한다. 열화·초기화·RPT 솔버를 따로 지정한다.
--rtol/--atol: 열화 궤적, --initial-rtol/--initial-atol: 초기 상태,
--rpt-rtol/--rpt-atol: 기준 용량 측정. 수치 설정은 체크포인트 신원에
포함되며, 변경된 설정으로 옛 체크포인트를 재개할 수 없다.

Q0와 Qref에는 동일한 RPT 허용오차·프로토콜을 적용한다. RPT는 원본의
복사본에서 진행하며 원본 상태 hash를 대조한다. 진단 중 열화는 복사본에만
반영한다. 마지막 목표가 5 EFC 미만이어도 끝점 RPT를 수행한다.
RPT의 정확한 전압/전류 종료 사건, 휴지 시간, 유한한 값, 1초 출력 간격을
검사한다. RPT에서 필요한 네 관측값만 저장하고 단계 전환에는 솔버가
보존하는 전체 최종 상태를 사용한다. 운전 궤적은 전체 상태를 유지한다.

simulation/audit_short_convergence.py: 로컬에서 실행하는 유한 검증.
simulation/convergence_contracts.py: 조합 누락·진단 실패·데이터 변이를
성공으로 처리하지 않는 독립 판정기.

짧은 비교 설계
전류 3.0/3.3 A × 메시 배율 4/8 × 열화 허용오차 3단계 = 12개 궤적.
열화 rtol/atol = 1e-4/1e-6, 1e-5/1e-7, 1e-6/1e-8.
aging 단계의 진단 rtol/atol은1e-8/1e-10으로 고정한다. 이 단계는 열화 궤적만
비교하며 항상 RPT 정밀도 미검증/전체 선별 비통과로 표시한다.
full 단계의 진단 rtol/atol = 1e-6/1e-8, 1e-7/1e-9, 1e-8/1e-10.
가장 정밀한 기준 측정이 로컬에서 약214초 걸려 두 단계를 분리했다.
한 궤적에서 이미 측정한 Q0/끝점RPT를 같은 정밀도로 다시 계산하지 않는다.
초기 상태는 각 메시에서 rtol=1e-8, atol=1e-10으로 새로 계산한다.
같은 메시 안에서는 모든 전류·열화 정밀도의 초기 상태 hash가 같아야 한다.
다른 메시로 상태를 옮기지 않고 Linux의 기존 체크포인트도 사용하지 않는다.

종료점 정의
메시8의 정밀 초기 Q0를 공통 방전량 기준으로 사용한다.
목표 1 EFC이면 모든 궤적을 정확히 이 공통 Q0 Ah를 방전한 곳에서 끝낸다.
설정마다 Q0가 조금 달라 비교 종료점까지 달라지는 혼입을 막기 위함이다.
이 검사의 EFC는 '공통 기준 방전 Ah / 공통 Q0'다. 각 메시 자체의 진단 Q0로
정의한 conventional_EFC도 따로 기록한다. SOH의 분모에는 해당 메시에서
Qref와 같은 진단 정밀도로 계산한 Q0를 사용한다.
일반 수명 엔진은 별도 기준을 지정하지 않으면 기존처럼 방전 Ah/고정 Q0다.

사전 판정 기준
입력 조합·종료점·원본 불변·전압/전류 종료·용량 적분 검사 모두 유효해야 한다.
각 전류의 SOH 자체 변화 범위는 0.0001 %p 이하여야 한다.
전류 간 ΔSOH의 허용 변화량은 아래 두 값 중 작은 값이다.
  0.0001 %p, 가장 정밀한 메시8 결과의 |ΔSOH| × 10%.
열화/메시 변경의 ΔSOH 범위, 같은 상태의 RPT 정밀도 변경 범위를 따로 비교한다.
모든 설정의 ΔSOH 부호도 같고 0이 아니어야 한다.
이는 실무적 사전 선별 기준이다. 엄밀한 오차 상한이나 실험 표준이 아니다.
작은 신호가 오차 범위와 분리되지 않으면 미해결로 남긴다.

실행
저장소에서 아래 명령을 실행한다. 출력 폴더는 새 경로여야 한다.
..\.venv\Scripts\python.exe simulation/audit_short_convergence.py --output ..\work\numerical_repair_20261103\NEW_RUN --stage aging --jobs 2 --anchor-source ..\work\numerical_repair_20261103\short_1efc_v2 --efc 1 --case-timeout-s 300 --wall-s 1800

anchor-source는 초기 용량 측정만 재사용한다. 원래 엔진/설정/패키지/환경과
원시 데이터 hash 및 보고서의 측정 증거가 일치해야 한다. 열화 상태를 다른
메시나 허용오차로 옮기지 않는다. 활성 직접 자식 프로세스는 최대2개이며,
각 시간 제한·전체 마감·중단에 종료하고 결과를 보존한다.
전체 진단 정밀도 비교는 별도 새 출력 폴더의 --stage full이다. 실제 관측한
소요시간에 맞춰 실행 한도를 검토해야 하며 시간초과를 성공으로 처리하지 않는다.

반환 코드: 0=full 단계의 짧은 선별 통과, 2=계산은 모두 완료했지만 정밀도 미통과
(aging 단계에서 계산이 모두 유효해도2),
1=계산 실패 또는 미완료. report.json의 execution_complete와
numerical_screen_pass는 서로 다른 항목이다. 실패 원시 표본과 로그를 보존한다.
RPT 자체가 실패한 값이나 부분 궤적을 정상 정답 라벨로 내보내지 않는다.
