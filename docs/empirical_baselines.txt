LG M50T empirical baseline comparison — 2026-11-03

Scope
This is an empirical comparison baseline, not a PyBaMM degradation calibration.
Both models are declared before D evaluation: constant SOH100 and
SOH = 100 - a*sqrt(calendar_days_since_RPT0/365) - b*ageing_EFC/1000,
with a,b nonnegative and estimated from C only by nonnegative least squares.
The C artifact is saved before D is loaded and its SHA-256 is unchanged afterward.
No temperature coefficient, D refitting, model selection by D, or EOL extrapolation
is performed. Previously inspected D summary statistics mean D is not newly blinded.

Definitions
Each cell uses its own measured RPT0 C/10 capacity for Q0 and SOH normalization.
Ageing EFC is the summary charge+discharge Ah divided by2fixedQ0. The source says
the summary ageing throughput excludes RPT/break-in. This definition is not the same
as discharge-only EFC recomputed from the incomplete cycle table.
Calendar input is RPT start date minus RPT0 start date, at day resolution.
The source's Days of degradation field is kept separately; it is not assumed to
represent total elapsed calendar time. Prediction uses known RPT/throughput schedules,
so this benchmark is not a blind future-EOL forecast.

Evaluate a frozen model on a reviewed additional-condition manifest
../.venv/Scripts/python.exe simulation/evaluate_frozen_baselines.py --model ../work/validation_proposal_20261103/baseline_v2/frozen_C_fit.json --manifest ../work/validation_proposal_20261103/baseline_D_manifest.json --output ../work/validation_proposal_20261103/NEW_EVALUATION

Manifest paths are resolved against the command working directory. Each entry
contains cell_id, summary_csv, source_receipt and condition with reviewed experiment/condition IDs,
temperature_setpoint_C, SOC_percent and source_refs. Only the reviewed Experiment2
SOC70–85 nominal25C and held-out10/40C conditions are accepted by this baseline
adapter. Training C cannot appear as an independent evaluation case. Raw bytes must
match one verified source-receipt member whose native cell/temperature agrees with
the condition. C calibration bytes or duplicate raw sources under aliases are rejected.
The frozen artifact pins the predictor implementation SHA-256. A changed predictor
or missing predictor provenance requires a newly declared/frozen version before evaluation.
